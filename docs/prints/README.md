## Leitura crítica

Os exemplos da resposta do Copilot não devem ser adotados como resultados reais ou orientações financeiras validadas. O exemplo de 10% para impostos é ilustrativo; a obrigação real depende do contexto. Separar honorários de repasses não basta para calcular lucro contábil. A mudança da margem não pode ser deduzida apenas da queda de faturamento. Integrações bancárias, investimentos e pagamentos permanecem fora do escopo do protótipo.
