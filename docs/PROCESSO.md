# Evolução do projeto com Vibe Coding

Registro resumido da conversa de desenvolvimento, sem representar um histórico de Copilot ou Lovable.

| Etapa | Orientação do usuário | Resultado |
| --- | --- | --- |
| 1 | Criar um app a partir do desafio de finanças com IA | Conceito inicial de organização financeira |
| 2 | Relacionar à profissão de marketing | Houve uma interpretação inicial como planejamento de conteúdo |
| 3 | “mas de finanças” | Correção de escopo: finanças para profissionais de marketing |
| 4 | “mude o nome para ByJohwGimenes MKT” | Nome aplicado ao aplicativo |
| 5 | Envio das logos | Identidade visual aplicada com versões de alto contraste |
| 6 | Preparar repositório para a DIO | Código e documentação organizados para entrega |

## Decisões de implementação

- HTML, CSS e JavaScript para simplificar execução e manutenção do protótipo.
- Dados fictícios para possibilitar demonstração imediata.
- Persistência local para evitar necessidade de backend no primeiro MVP.
- Assistente identificado como simulação, porque não houve integração real com um modelo de IA.
- Aplicativo publicado de forma privada para demonstração ao proprietário.

## Aprendizado observado

A correção “mas de finanças” foi decisiva para manter o objetivo original. Informar somente a profissão não definia se o produto deveria organizar conteúdos ou administrar o dinheiro da atividade. O briefing final passou a explicitar domínio, funcionalidades, público e limites.
